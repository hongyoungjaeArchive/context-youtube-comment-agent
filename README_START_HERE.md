## 오늘 마감에 관한 현실 확인

PDF 및 문서 완성은 **과제 제출 완료와 다르다.** 원본 과제는 2~3분 **실제 동작 시연 영상**을 필수 제출물로 명시하고, Git 저장소는 선택 사항이다. 2026-10-20에 문서만 있는 상태라면 실제 게시·확인 기능을 시연한 것처럼 표현하지 않는다. 자세한 증빙·최종 제출 체크리스트는 `docs/14_RELEASE_DEMO.md` 참조.

## 정책·실행 범위

- 자동 게시 검증은 **본인이 소유·통제하는 테스트 영상**에 한정한다. 실제 대상 5개 채널에서는 조사·분석·투명한 홍보 초안까지만 지원한다.
- 광고 관계를 숨긴 제3자 시청자 행세, 다계정 순환 홍보, 스팸 게시, CAPTCHA 우회, 인증 회피는 범위 밖이다.
- 공식 과제에는 시청자 페르소나의 자연스러운 브랜드 유도가 요구되지만, 이 명세는 기만적·반복적 프로모션을 그대로 자동화하지 않는다. **과제 의도와 안전 범위의 차이**를 명시적으로 문서화한다.
