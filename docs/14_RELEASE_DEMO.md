# 14. 제출·시연 계획 (2026-10-21 개정)

> 제출물: 시연 영상 2~3분(필수) + 제작 의도(`deliverables/INTENT.md`) + Git 저장소(선택).
> 성공하지 않은 장면을 성공처럼 편집하지 않는다. 편집으로 줄인 대기 시간은 화면 자막으로 밝힌다.

## 2. 시연 스토리보드 (목표 2분 30초, 평가표 순서)

| 시간 | 화면·조작 | 화면 자막(또는 내레이션) | 평가 |
|---|---|---|---|
| 0:00–0:10 | 대시보드 전체 | "영상 불러오기 → 고르기 → 댓글 달기, 세 칸이면 끝나는 로컬 대시보드" | 사용성 |
| 0:10–0:30 | ① **[영상 불러오기]** → 5개 채널 결과(✓) → 썸네일·제목·채널·날짜 목록 | "지정 5개 채널 최신 영상" | 실제 게시(동선) |
| 0:30–0:40 | 링크 입력칸에 지정 채널 밖 영상 링크 → **차단** 메시지 | "허용 범위 밖 링크는 채널을 확인해 막음" | 운영 규칙 |
| 0:40–1:15 | 영상 클릭 → ② 고민 한 줄 + 추천 초안. 초안 카드의 "자막 발언 반영 (m:ss)" 강조. [다른 초안 2개 보기]를 잠깐 펼침 | "AI가 자막·인기 댓글을 읽고 고민을 정리한 뒤, 그 영상의 말을 짚어 댓글 작성" | 맥락 25·유도 20 |
| 1:15–1:30 | 다른 채널 영상 하나 더 클릭 → 전혀 다른 초안 | "영상마다 다른 댓글" | 맥락 |
| 1:30–2:10 | ③ 테스트 영상·유튜브1 선택 → 승인 → **[댓글 달기]** → 확인 → Chrome 창: 댓글창 → **한 글자씩 입력** → 게시 → 내 댓글 보임(5초 유지) → 대시보드 `SUCCESS` | "실제 게시는 본인 테스트 영상에만" | 실제 게시 25 |
| 2:10–2:20 | 같은 영상에 다시 [댓글 달기] → `VIDEO_ALREADY_CLAIMED` 차단. 헤더 "오늘 게시 n/10" | "영상당 1개 · 하루 10개, 서버에서 강제" | 운영 규칙 |
| 2:20–2:30 | [실행 기록] → 영상·프로필·댓글·성공/실패 시간순 | "모든 시도를 시간순 기록, 실패하면 이유와 캡처" | 운영 규칙 |
| (선택) +10초 | ① [뜨기 직전 찾기] → 결과 목록 "초안까지만" | "가점: '연애' 뜨기 직전 영상, 초안까지만" | 가점 |

- 분석 대기 장면을 줄였다면 그 구간에 "실제 분석 약 1분 — 편집으로 단축" 자막을 넣는다.
- Chrome 타이핑 장면은 자르지 않는다. 평가 핵심 장면이기 때문이다.

## 3. 제출 전 체크 (과제 원문 p.7)

- [ ] 시연 영상 링크를 **로그인하지 않은 창**에서 열어도 재생된다 (Drive 링크가 있는 모든 사용자 또는 YouTube 일부 공개)
- [ ] 영상에 세 칸 사용 → 한 글자씩 타이핑 → 게시 → 내 댓글 확인이 모두 나온다
- [ ] (Git을 낸다면) `npm run secret-scan` 0건, `.env`·DB·프로필 폴더·`.reel/` 미포함
- [ ] 제작 의도: `deliverables/INTENT.md` 내용 붙여넣기
- [ ] 제출 양식: 2번 트랙, 영상 링크, Git 주소(선택), 성함·연락처·나이·자기소개
- [ ] 정확한 마감 시각 확인
